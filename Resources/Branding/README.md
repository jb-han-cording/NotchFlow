# NotchFlow app icon

Created with the built-in image_gen tool using the imagegen skill. The PNG is the source asset; `scripts/build-icon.sh` packages standard macOS sizes into `Resources/AppIcon.icns`. This icon is included in the app's resources and referenced by CFBundleIconFile. The menu-bar symbol remains monochrome for legibility.

## Generation prompt

Use case: logo-brand. Asset type: production macOS app icon for NotchFlow, a native MacBook notch productivity app with a black and mint UI. Create one square 1024x1024 icon, front-on and centered. Transparent exterior background. Large dark graphite rounded-square macOS icon tile with restrained satin shading. Center a single bold luminous mint-to-teal shape suggesting a MacBook top notch expanding downward into a compact rounded floating island, with a deliberate dark notch-shaped indentation at its top center. Minimal, elegant, highly legible at 32 pixels. Restrained soft depth, crisp silhouette, generous space around the symbol, tile fills about 88% of canvas. No lettering, no words, no waveform or equalizer, no music note, no device mockup, no collage, no branding from existing apps. Deliver a finished app icon asset.
