## 노치에서 바로 하는 일

NotchFlow는 평소에는 노치 크기로 조용히 머물다가 마우스를 올리거나 클릭하면 부드럽게 펼쳐집니다. 필요한 기능은 한 화면에서 짧고 빠르게 확인할 수 있습니다.

- **음악** — Apple Music 또는 Spotify를 연결해 현재 곡을 보고 이전 곡, 재생·일시 정지, 다음 곡을 제어합니다. 곡이 바뀔 때 음악 화면을 자동으로 펼칠지 선택할 수 있습니다.
- **캘린더** — 오늘 일정과 다음 일정을 확인하고 일정 시작 전 알림을 받습니다.
- **파일 선반** — 잠시 사용할 파일과 폴더를 노치에 올려두고 다시 꺼냅니다. 원본 파일은 이동하거나 삭제하지 않습니다.
- **빠른 메모** — 떠오른 내용을 바로 기록하고 체크리스트로 관리합니다. 내용은 이 Mac에 자동 저장됩니다.
- **집중 타이머** — 노치 또는 메뉴 막대에서 타이머를 시작하고 남은 시간을 확인합니다.
- **메뉴 막대** — 노치를 펼치지 않고도 모듈과 타이머에 접근할 수 있으며, 원하면 메뉴 막대 아이콘을 숨길 수 있습니다.

노치가 없는 Mac이나 외부 모니터에서도 화면 위쪽 중앙에 작은 플로팅 아일랜드로 사용할 수 있습니다.

## 설치 방법

### 0.3.4에서 새로워진 기능

- **앱별 자동 숨김** — 설정 → 일반에서 앱을 추가하면 해당 앱이 활성화된 동안 패널을 숨기고, 다른 앱으로 전환하면 다시 표시합니다.
- **배터리·충전 알림** — 전원 연결·분리, 배터리 20%·10% 이하, 충전 완료를 알려줍니다. 설정 → 알림에서 켜고 끌 수 있습니다.
- **다음 회의 참가** — 캘린더 일정의 링크·장소·메모에서 Zoom, Google Meet, Teams 주소를 찾아 다음 회의의 참가 버튼을 표시합니다.
- **파일 선반 자동 정리** — 설정 → 모듈에서 1시간·하루·일주일을 선택합니다. 기본값은 꺼짐이며, 추가 시점을 기준으로 오래된 참조만 제거하고 원본 파일은 유지합니다.
- **대기 상태 유리 효과** — 노치가 없는 화면에서도 리퀴드 글래스 설정을 켜면 접힌 패널에 유리 효과가 표시됩니다.

### 다운로드 및 실행

1. [NotchFlow-0.3.4.dmg를 다운로드](https://github.com/jb-han-cording/NotchFlow/raw/refs/heads/main/dist/NotchFlow-0.3.4.dmg)합니다.
2. 다운로드한 DMG를 열고 **NotchFlow**를 **Applications** 폴더로 옮깁니다.
3. 응용 프로그램 폴더에서 NotchFlow를 실행합니다.
4. macOS가 개발자를 확인할 수 없다는 메시지를 표시하면 앱을 Control-클릭한 뒤 **열기**를 선택합니다.

NotchFlow는 메뉴 막대 앱이라 Dock에 아이콘이나 일반 창이 나타나지 않습니다. 실행 후 화면 위쪽의 노치 또는 메뉴 막대 아이콘을 확인해 주세요.

## 처음 사용할 때

첫 실행 안내에 따라 필요한 기능만 연결하면 됩니다.

1. 노치를 클릭해 NotchFlow를 펼칩니다.
2. **설정 → 연결**에서 사용할 음악 앱과 캘린더를 연결합니다.
3. macOS 권한 창이 나타나면 사용할 기능의 접근을 허용합니다.
4. **설정 → 모듈**에서 노치에 표시할 기능을 선택합니다.

기본 전역 단축키는 **Option + Space**입니다. 설정에서 다른 조합으로 변경하거나 끌 수 있습니다.

## 권한이 작동하지 않을 때

### 음악이 표시되지 않아요

- Apple Music 또는 Spotify 데스크톱 앱을 먼저 실행하고 음악을 재생해 주세요.
- **설정 → 연결 → 음악 앱 연결**에서 사용할 앱을 선택하고 연결을 다시 시도해 주세요.
- 연결이 거부되었다면 **시스템 설정 → 개인정보 보호 및 보안 → 자동화**에서 NotchFlow의 접근을 허용해 주세요.

브라우저, YouTube, 팟캐스트 및 다른 오디오 앱은 macOS가 시스템 미디어 정보를 제공하는 경우 자동으로 재생 정보가 표시됩니다. 해당 앱의 이전 곡·재생·다음 곡 제어는 지원하지 않을 수 있습니다.

### 캘린더 권한 창이 나타나지 않아요

- **설정 → 연결 → 캘린더 연결**에서 권한을 다시 요청해 주세요.
- 이전에 거부했다면 **시스템 설정 → 개인정보 보호 및 보안 → 캘린더 → NotchFlow**에서 전체 접근을 허용해 주세요.
- 권한을 변경한 뒤에는 NotchFlow를 다시 실행해 주세요.

## 내 취향에 맞게 설정하기

설정에서 다음 항목을 조절할 수 있습니다.

- 표시할 모듈과 기본 화면
- 호버 및 클릭 동작
- 노치 너비, 곡률, 투명도, 블러와 테마
- 애니메이션 속도와 macOS 동작 줄이기 설정 반영
- 곡 변경 시 음악 화면 자동 펼치기
- 일정, 파일과 메모 알림
- 로그인 시 자동 실행
- 메뉴 막대 아이콘 표시 여부
- 자동 업데이트 확인

## 업데이트

**설정 → 업데이트**에서 새 버전을 확인하고 다운로드할 수 있습니다. 새 앱으로 교체해도 기존 설정, 메모와 파일 선반 정보는 그대로 유지됩니다.

직접 업데이트하려면 NotchFlow를 종료한 뒤 새 DMG의 앱을 Applications 폴더에 덮어쓰면 됩니다.

## 개인정보와 로컬 저장

NotchFlow는 메모, 일정과 파일 목록을 외부로 전송하지 않으며 분석 도구나 사용자 추적 기능을 포함하지 않습니다. 사용자 데이터는 다음 위치에 로컬로 저장됩니다.

`~/Library/Application Support/NotchFlow/`

- 음악 정보는 연결한 플레이어에서만 읽습니다.
- 캘린더는 오늘의 일정을 표시하기 위해 사용합니다.
- 파일 선반은 사용자가 직접 추가한 파일의 참조만 저장합니다.
- 업데이트 확인을 켠 경우에만 GitHub에서 버전 정보와 DMG를 받습니다.

## 알아두기

- 지원 운영체제는 **macOS 14.0 이상**입니다.
- 음악 제어 연동은 **Apple Music**과 **Spotify 데스크톱 앱**을 지원합니다. 그 밖의 앱도 macOS 시스템 미디어 정보가 제공되면 제목·아티스트·재생 상태·앨범 이미지를 표시합니다.
- Spotify 앨범 이미지는 현재 기본 음악 아이콘으로 표시될 수 있습니다.
- 일정 알림은 NotchFlow가 실행 중일 때 제공됩니다.
- MacBook 모델, 외부 모니터, 전체 화면 앱과 메뉴 막대 자동 숨김 설정에 따라 노치 위치가 조금 다르게 보일 수 있습니다. 화면 선택과 노치 너비는 설정에서 조절할 수 있습니다.

문제가 있거나 원하는 기능이 있다면 [GitHub Issues](https://github.com/jb-han-cording/NotchFlow/issues)에 남겨주세요.
